# Hack le Serveur - Jeu Backend

## Description
Un mini-jeu pour apprendre le backend en modifiant le code pour débloquer des niveaux.

## Installation
1. Installe Node.js (https://nodejs.org)
2. Dans le dossier du projet, exécute :
   ```bash
   npm init -y
   npm install
   ```

## Lancer le jeu
```bash
npx nodemon server.js

```
Puis ouvre `frontend/index.html` dans ton navigateur.

## Objectif
- Niveau 1 : Mets `access = true` dans server.js
- Niveau 2 : Trouve le bon mot de passe (variable `password`)
- Niveau 3 : Mets `secretButton = true`
- Niveau 4 : Augmente `score > 100`

Amuse-toi à hacker le serveur !
